# CS101 Python Exercise

A foundational Python command-line project that standardizes the classic estimation prompt: "How many balls can fit into an airplane?"

The program asks the user to define an airplane model and ball model, calculates estimated volumes, compares the ball volume against the plane cabin volume, and stores a short history of recent calculations.

## Files

```text
.
`-- cs101_python.py
```

## Concepts Demonstrated

- User input handling
- Functions and reusable calculation steps
- Lists for storing input values and calculation history
- Conditional logic and loops
- Basic geometry and estimation
- Command-line program flow

## How to Run

From this folder, run:

```powershell
python cs101_python.py
```

The program provides default values for a Boeing 737 and a basketball, but it also accepts custom plane and ball dimensions.

## Notes

This is an introductory programming exercise rather than a production calculator. The source comments include possible future improvements, especially around stronger input validation and code organization.
