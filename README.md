# Portfolio

Welcome to my portfolio repository! This collection highlights practical work across business intelligence, data analysis, computer vision, and foundational Python programming.

The projects here are organized as reviewable examples of how I approach problem solving: understanding the business or technical question, preparing the data or inputs, building the analysis or application, and presenting the result clearly.

## Focus Areas

- Business intelligence reporting and spreadsheet-based analysis
- Exploratory data analysis, data cleaning, and metric validation
- Python analysis with pandas, NumPy, SciPy, Matplotlib, and Seaborn

## Featured Work

### Interactive Facial Detection Streamlit Web App

A lightweight computer vision app that detects faces in uploaded images using MediaPipe's TFLite face detector. The app reports detected face count, inference time, confidence scores, and side-by-side visual output with bounding boxes.

**Tools:** Python, Streamlit, MediaPipe, TFLite, NumPy, Pillow

### Marketing and Advertising Analysis

A Python notebook analyzing multichannel marketing campaign performance for a direct-to-consumer fitness supplements brand. The analysis covers data quality, metric validation, ROAS performance, creative and audience patterns, spend allocation, and regression-based recommendations.

**Tools:** Python, pandas, NumPy, Excel

### National Park Biodiversity Analysis

An exploratory and statistical analysis of species observations and conservation status across national parks. The project includes data inspection, category-level summaries, protected-species analysis, visualization, and chi-squared hypothesis testing.

**Tools:** Python, pandas, SciPy, Matplotlib, Seaborn

### Bitcoin Analysis Excel

An Excel-based analysis project using Bitcoin market data from a CSV source and workbook deliverable.

**Tools:** Microsoft Excel, CSV data analysis

### Business Intelligence Report

An obfuscated Excel report and matching PDF export that demonstrate spreadsheet-based reporting, workbook organization, and presentation-ready deliverables.

**Tools:** Microsoft Excel, PDF reporting

### CS101 Python Exercise

A command-line Python project that standardizes the classic interview-style estimation problem: "How many balls can fit into an airplane?" The program accepts user-defined plane and ball dimensions, calculates estimated fit, and keeps a short calculation history.

**Tools:** Python

## How to Navigate

There is no single setup process for the whole repository because each folder represents a different type of project. Start with the folder that matches the work you want to review:

- For app development, see `Computer Vision/Interactive Facial Detection Streamlit Web App/`.
- For Python analytics, see the analysis projects under `Business Intelligence and Data Analysis/`.
- For spreadsheet reporting, open the Excel and PDF deliverables in `Business Intelligence and Data Analysis/`.
- For introductory Python practice, see `Computer Science/cs101_python.py`.

The Streamlit face detection app includes its own project-level README with setup and usage instructions.

## Notes

Some business intelligence materials are obfuscated before upload to protect the original source data and business context while still showing the reporting structure and deliverable format.
