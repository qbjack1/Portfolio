# Business Intelligence and Data Analysis

This folder contains portfolio projects focused on spreadsheet reporting, Python-based data analysis, campaign performance analysis, and exploratory statistics.

The work here is meant to show both delivery formats: polished business-facing reports and hands-on analysis projects with source data, notebooks, scripts, and workbook outputs.

## Included Projects

### Business Intelligence Report

The top-level Excel workbook and PDF export demonstrate a reporting deliverable with structured workbook tabs, report packaging, data-quality checks, and SQL-related analysis material.

**Files:**

- `sample_obfuscated_excel_report.xlsx`
- `obfuscated_report.pdf`

**Workbook tabs include:** `README`, `MASTER_Monthly`, `REPORT_Pack`, `DQ_Checks`, and `SQL_Bonus`.

### Bitcoin Analysis Excel

An Excel workbook built from Bitcoin market data, with analysis tabs for daily and monthly patterns, upside, spread, daily highs, and a final recommendation.

See `Bitcoin Analysis Excel/README.md`.

### Marketing and Advertising Analysis Python

A Python notebook analyzing multichannel marketing performance for a direct-to-consumer fitness supplements brand.

See `Marketing and Advertising Analysis Python/README.md`.

### National Park Biodiversity Python

A Python analysis project exploring species, observations, conservation status, and statistical relationships across national parks.

See `National Park Biodiversity python/README.md`.
