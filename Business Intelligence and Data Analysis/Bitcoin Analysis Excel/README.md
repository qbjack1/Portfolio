# Bitcoin Analysis Excel

An Excel-based analysis project using Bitcoin market data from a CSV source. The workbook organizes the data into analysis tabs that review price movement, upside, spread, monthly averages, daily highs, and a final recommendation.

## Files

```text
.
|-- bitcoin_analysis.xlsx
`-- data.csv
```

## Data

The CSV contains daily BTCUSD market records with the following fields:

- `Date`
- `Month`
- `Symbol`
- `Open`
- `High`
- `Low`
- `Close`
- `Volume`

## Workbook Structure

The workbook includes these sheets:

- `data`
- `Upside`
- `Spread`
- `Monthly Average`
- `Daily High`
- `Final Recommendation`

## Skills Demonstrated

- Spreadsheet-based market data analysis
- Organizing raw CSV data into workbook tabs
- Comparing daily price movement and spread
- Summarizing monthly trends
- Presenting a final recommendation in Excel

## How to Review

Open `bitcoin_analysis.xlsx` in Microsoft Excel or a compatible spreadsheet application. Start with the `Final Recommendation` sheet, then review the supporting analysis tabs for the underlying calculations and summaries.

The `data.csv` file is included as the source dataset behind the workbook.
